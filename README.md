# ZollPilot

ZollPilot ist eine Applikation zur strukturierten Erfassung und Verwaltung von Zolldaten.
Das Projekt wird in einem sprint-basierten Entwicklungsprozess aufgebaut, bei dem jede Phase klar definierte Ziele und Akzeptanzkriterien hat.
Die technische Architektur und der Stack werden in den kommenden Phasen festgelegt.
