## 🎬 3-Minuten-Demo-Skript

- Browser auf `http://localhost:3000/declarations`.

    *   *Zeigen:* Dashboard (Leer oder Liste).
    *   *Sagen:* "Willkommen bei ZollPilot. Dies ist der MVP für die Erfassung von Ausfuhranmeldungen (IAA). Wir fokussieren uns auf einfache, geführte Dateneingabe."

2.  **Der Flow (0:30-2:00):**
    *   *Klick:* "+ Neue Anmeldung".
    *   *Sagen:* "Der Wizard führt uns Schritt für Schritt. Hier erfassen wir Versender und Empfänger." (Daten eingeben: 'Test GmbH', 'Musterstr.').
    *   *Klick:* "Weiter".

    *   *Klick:* "Weiter" -> "Position hinzufügen".

3.  **Abschluss (2:00-2:45):**

    *   *Sagen:* "Zusammenfassung aller Daten vor der finalen Abgabe."
    *   *Klick:* "Kostenpflichtig Abschließen".

## ⚠️ Known Limitations
Offene Punkte, die in Phase 1 bewusst nicht gelöst wurden:
1.  **Keine ATLAS-Anbindung:** Die Daten verlassen das System nicht (nur interne Speicherung).
2.  **Mock PDF:** Das PDF ist visuell rudimentär und kein offizielles Formular 033025.
3.  **Prototyping DB:** Wir nutzen `db push` statt echter Migrationen.
4.  **Single Tenant:** Keine Unterscheidung zwischen Nutzern oder Mandanten im UI (im Backend vorbereitet).
5.  **Tarif:** Keine echte Prüfung von Warennummern gegen den EZT.
